# WireMason

A local HTTP(S) debugging proxy for Mac and Linux: capture, search, rewrite, mock, and replay your app's traffic, with a CLI and an MCP server for AI coding agents.

- Website and downloads: https://wiremason.smallmarvel.com
- macOS: Developer ID signed and notarized DMG for Apple silicon
- Linux: x86_64 AppImage

Every release here is produced by an isolated release broker from a CI-validated build. Each asset ships with a `.sha256`, and the update manifests are Ed25519-signed. Installed copies check this repository and update themselves.
